API Clima 🌤️ - Arthur Guidolin
Projeto simples de consulta de clima, feito com HTML, CSS e JavaScript puro, sem frameworks, sem bibliotecas externas e sem backend.

APIs utilizadas
Geocoding: https://geocoding-api.open-meteo.com/v1/search
Clima: https://api.open-meteo.com/v1/forecast
Nenhuma das duas pede chave de API (API Key).

Requisições HTTP com fetch()
Trabalhar com respostas em formato JSON
Encadear duas chamadas de API (geocoding → clima)
Tratamento de erros (try/catch) em código assíncrono
Manipulação do DOM para atualizar a interface dinamicamente
Organização de funções pequenas e específicas
